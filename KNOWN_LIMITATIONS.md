# Known Limitations

> **PRACTICE BUILD — NOT CLAIMED AS EVENT-DAY WORK**

1. AI roles are deterministic local adapters. There is no live LLM or MuleRun runtime integration.
2. Extraction supports the three synthetic fixtures and a conservative all-unknown manual fallback; it is not general natural-language extraction.
3. State and audit evidence exist only in Streamlit session memory and disappear when the session resets.
4. There is no authentication, authorization, multi-tenancy, database, encryption-at-rest design or production secret management.
5. The M365 recommendation is an architecture suggestion only. Licensing, tenant configuration, connectors, information governance and production feasibility are not validated.
6. Qualification is a prototype decision aid. It is not customer discovery, market validation, ROI evidence or an approved commercial proposal.
7. The reviewer uses controlled deterministic modes. It does not perform semantic code review or independent live-model reasoning.
8. Markdown report generation is local and human-gated. There is no PDF generation, e-signature, external sending or immutable evidence store.
9. Accessibility, browser compatibility, performance, dependency audit, secret scan, CI and production deployment have not been completed.
10. The application uses synthetic data only and must not be used with real client, personal, confidential or regulated data.
