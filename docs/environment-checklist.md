# Environment Checklist

The preparation script must verify or record:

- Python;
- Git;
- VS Code command-line launcher;
- virtual environment;
- pytest;
- Ruff;
- Streamlit;
- Pydantic;
- repository folder;
- evidence folders;
- `.gitignore` and `.env.example`;
- practice-build disclosure;
- initial commit;
- `pre-hackathon-baseline` tag.

A missing VS Code command-line launcher is a warning when VS Code can still open the folder manually.

A missing Python or Git installation is a blocking failure.
